# AGENTS.md — wp_block_theme

## What this is
A lightweight, responsive WordPress block theme fully compatible with the Gutenberg block editor and Full Site Editing (FSE).

## Stack
- WordPress Block Theme (FSE)
- HTML/CSS/PHP templates

## Build
No build step; theme files are placed directly in WordPress.

## Run
Install as a WordPress theme in `wp-content/themes/` and activate via WordPress admin.

## Structure
- `templates/` — FSE block templates
- `styles/` — theme style variations
- `theme.json` — theme configuration
- `functions.php` — theme functions

## Conventions
- No comments in code unless asked.
- Follow WordPress block theme conventions.
